# React + Vite

WTWR (What To Wear) is a responsive weather-based web application that helps users decide what clothing to wear based on real-time weather conditions. The app automatically detects the user’s location, fetches current weather data, and displays clothing recommendations tailored to the temperature and weather conditions.

Features

### Fetches real-time weather data from the OpenWeather API

### Displays clothing recommendations based on temperature and conditions

### Supports day and night weather visuals

### Allows users to add custom clothing items

### Accessible UI with descriptive alt text

Technologies Used

React

JavaScript (ES6+)

HTML5

CSS3

OpenWeather API
